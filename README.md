# soda-docs

Public operator documentation site for SODA — https://somarobotics.github.io/soda-docs/

Content under `docs/` is synced from `soda-bimanual/docs/customer/` by that repo's
`publish-docs` workflow on every release — **edit the source there, not here.**
`mkdocs.yml` and the deploy workflow are owned by this repo.
